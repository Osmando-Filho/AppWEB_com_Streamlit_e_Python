1. Descrição do App: Tirar Foto (Webcam)

Este aplicativo web simples, desenvolvido em Python utilizando o framework Streamlit, permite a captura rápida de imagens diretamente da webcam do seu dispositivo.

É uma ferramenta prática para situações que exigem uma foto imediata, como validação de documentos, criação de perfis ou registros rápidos, sem a necessidade de upload de arquivos.

Funcionalidades Principais:
Acesso Direto à Câmera: Utiliza o componente st.camera_input para acessar e tirar fotos instantâneas.
Pré-visualização Instantânea: Exibe a foto capturada na interface do Streamlit para confirmação.
Download Imediato: Permite o download da imagem capturada (.png) com um único clique, garantindo agilidade no fluxo de trabalho.

Propósito: Demonstra proficiência na integração de componentes de hardware e desenvolvimento de interfaces de usuário rápidas com Streamlit.

2. Descrição do App: Conversor de Texto em Áudio (Text-to-Speech - TTS)

Este aplicativo web é uma ferramenta de Conversão de Texto em Áudio (TTS) construída em Python e Streamlit, projetada para transformar qualquer texto escrito em fala.

É ideal para a criação de conteúdo acessível, aprimoramento de materiais de e-learning, ou para quem precisa ouvir rascunhos de textos e documentos.

Funcionalidades Principais:

Entrada de Texto Flexível: Possui uma área de texto para que o usuário insira parágrafos, frases ou grandes blocos de conteúdo.
Geração de Áudio: Processa o texto inserido e gera a saída de voz usando bibliotecas de síntese de fala (TTS).
Reprodução e Download: Permite que o usuário ouça o áudio gerado diretamente no navegador e baixe o arquivo (geralmente MP3 ou WAV) para uso offline.

Propósito: Serve como um portfólio que destaca a habilidade em utilizar bibliotecas avançadas de Processamento de Linguagem Natural (NLP) e criar soluções de acessibilidade com Streamlit.

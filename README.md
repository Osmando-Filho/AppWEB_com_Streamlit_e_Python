# 📸 Streamlit Camera App

Este é um projeto simples que demonstra o uso do componente `st.camera_input` do Streamlit para capturar imagens diretamente da webcam do usuário e permitir o download imediato da foto tirada.

O aplicativo é perfeito para tarefas rápidas que exigem captura de imagem sem a necessidade de upload de arquivos.

## 🌟 Funcionalidades

* **Captura de Foto:** Utiliza a webcam do dispositivo para tirar fotos.
* **Pré-visualização:** Exibe a foto capturada imediatamente na interface.
* **Download:** Permite o download da imagem capturada como um arquivo `.png`.

## ⚙️ Tecnologias Utilizadas

* **Python:** Linguagem de programação principal.
* **Streamlit:** Framework para criação de aplicativos web de dados de forma rápida.

## 🚀 Como Executar o Aplicativo

Para rodar este aplicativo em sua máquina local, siga os passos abaixo:

### 1. Pré-requisitos

Certifique-se de ter o Python 3.7 ou superior instalado em seu sistema.

### 2. Configuração do Ambiente

É altamente recomendável utilizar um ambiente virtual (venv):

# Crie o ambiente virtual
python -m venv venv

# Ative o ambiente virtual
# No Windows (PowerShell):
.\venv\Scripts\activate

# No Linux/macOS:
source venv/bin/activate

### 3. Instalação de Dependências
# Instale a biblioteca Streamlit:
pip install streamlit

### 4. Execução
# Com o ambiente virtual ativado, execute o script (foto.py) usando o comando do Streamlit:

streamlit run foto.py
Após executar o comando, o Streamlit abrirá automaticamente o aplicativo no seu navegador padrão, geralmente no endereço: 
http://localhost:8501.
